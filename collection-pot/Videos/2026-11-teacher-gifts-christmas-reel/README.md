# Teacher gifts: Christmas Reel

| | |
|---|---|
| **Brief** | Turn the "Teacher gifts made effortless" emailer into an Instagram Reel for Christmas class gifting. |
| **Source** | `source-email.md` (the email's copy, verbatim) |
| **Channel** | Instagram Reels |
| **Format** | 1080×1920, 30 fps, 25 to 30 s, music and sound effects, no voiceover |
| **Tools** | Higgsfield (live-action plates, no faces) + HyperFrames (type, Chip, logo, edit, render) |
| **Chip** | 3D renders only (no 2D Chip in this piece) |
| **Status** | Step 1: script, waiting for a storyline pick |

## Files
- `SCRIPT.md`: three storylines with a shot-by-shot script each, plus the Instagram caption draft
- `STORYBOARD.md`: step 2 (to come)
- `higgsfield/`: Higgsfield prompts and the clips they made (to come)
- `project/`: the HyperFrames project (to come)
- `export/`: the final render, `teacher-gifts-christmas-reel_1080x1920.mp4` (to come)

## Rules for this piece
- No people's faces anywhere. Live-action shots show hands, objects and places only.
- Chip, the logo, the Pot icon and the printed card come from `../../brand/` unchanged. They're never recreated or AI-generated.
